1. Create a new repository on GitHub named:
   **`Swasthik-Acharya-SK.github.io`**
2. Upload all the files inside this `portfolio` folder (`index.html`, `assets/`, etc.) into that repository.
3. Done! Within 1-2 minutes, your website is live at:
   👉 **`https://swasthik-acharya-sk.github.io`**

### Option 2: As a repository page
1. Create a repository named `portfolio` on GitHub.
2. Push or upload these files.
3. In GitHub, go to **Settings** > **Pages** > Under "Branch", select **main** (or master) and root `/` > Click **Save**.
4. Your website will be live at:
   👉 **`https://swasthik-acharya-sk.github.io/portfolio`**
